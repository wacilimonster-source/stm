## 2. SillyTavern API 分析

### 2.1 认证机制

SillyTavern 使用 Cookie Session 认证。

**登录流程**：
```http
POST /api/users/public/list
POST /api/users/public/login
Body: { "handle": "用户名", "password": "密码" }
Response: 设置 Cookie，后续请求自动带上
```

**关键发现**：
- 无需单独注册，登录即创建用户
- Cookie 由 `cookie-session` 中间件管理
- 所有 API 请求需要携带 Cookie

### 2.2 核心 API 端点

| 功能 | 端点 | 方法 | 请求体 |
|------|------|------|--------|
| 检查服务 | `GET /` | GET | - |
| 用户列表 | `POST /api/users/public/list` | POST | `{}` |
| 用户登录 | `POST /api/users/public/login` | POST | `{handle, password}` |
| 角色列表 | `POST /api/characters/all` | POST | `{}` |
| 角色详情 | `POST /api/characters/get` | POST | `{avatar_url: "角色名.png"}` |
| 最近聊天 | `POST /api/chats/recent` | POST | `{max: 20, pinned: []}` |
| 获取聊天 | `POST /api/chats/get` | POST | `{avatar_url, file_name}` |
| 保存聊天 | `POST /api/chats/save` | POST | `{avatar_url, file_name, chat: [...]}` |
| 发送消息 | `POST /api/backends/chat-completions/generate` | POST | 见下文 |
| 世界书列表 | `POST /api/worldinfo/list` | POST | `{}` |
| 世界书详情 | `POST /api/worldinfo/get` | POST | `{name: "文件名"}` |
| 世界书编辑 | `POST /api/worldinfo/edit` | POST | `{name, data: {entries: {...}}}` |

### 2.3 发送消息 API

**请求格式**：
```json
POST /api/backends/chat-completions/generate
{
  "chat_completion_source": "openai",  // 或其他provider
  "model": "gpt-4",
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "用户输入"}
  ],
  "stream": true
}
```

**关键字段**：
- `stream: true` 启用流式输出
- `messages` 需要包含完整的上下文（系统提示、聊天历史）
- SillyTavern 会自动处理世界书注入、宏替换等

### 2.4 流式响应 (SSE)

**响应格式**：SSE (Server-Sent Events)，直接转发 LLM provider 的响应。

**Flutter 处理方式**：
```dart
final response = await dio.post(
  '/api/backends/chat-completions/generate',
  data: requestBody,
  options: Options(responseType: ResponseType.stream),
);
```

**数据格式**：取决于 LLM provider，通常是：
```
data: {"choices":[{"delta":{"content":"你"}}]}
data: {"choices":[{"delta":{"content":"好"}}]}
data: [DONE]
```

## 3. 数据格式分析

### 3.1 角色卡

**格式**：PNG 图片内嵌 JSON
- V2: `chara` 字段 (base64 编码)
- V3: `ccv3` 字段 (base64 编码)

**Flutter 解析**：
```dart
import 'dart:convert';
import 'dart:typed_data';
import 'package:png/png.dart';

Map<String, dynamic> parseCharacterCard(Uint8List bytes) {
  final png = PngParser.parse(bytes);
  for (final chunk in png.chunks) {
    if (chunk is PngTextChunk && chunk.keyword == 'ccv3') {
      final jsonStr = utf8.decode(base64Decode(chunk.text));
      return json.decode(jsonStr);
    }
  }
  throw Exception('Invalid character card');
}
```

**角色数据结构**（简化）：
```json
{
  "spec": "chara_card_v3",
  "data": {
    "name": "角色名",
    "description": "角色描述",
    "personality": "性格",
    "scenario": "场景",
    "first_message": "第一句话",
    "avatar": "图片base64或url"
  }
}
```

### 3.2 聊天记录

**格式**：JSONL (每行一个 JSON 对象)

**消息结构**：
```json
{
  "role": "user",           // 或 "assistant"
  "name": "用户名",
  "is_user": true,
  "mes": "消息内容",
  "send_date": "2024-01-15T10:30:00.000Z"
}
```

**Flutter 解析**：
```dart
List<ChatMessage> parseChatHistory(String jsonl) {
  return jsonl
      .split('\n')
      .where((line) => line.isNotEmpty)
      .map((line) => ChatMessage.fromJson(json.decode(line)))
      .toList();
}
```

### 3.3 世界书

**格式**：JSON 文件

**结构**：
```json
{
  "name": "世界书名称",
  "entries": {
    "entry-uuid-1": {
      "key": ["关键词1", "关键词2"],
      "secondary_keys": ["次要关键词"],
      "content": "这里是内容...",
      "insertion_order": 1,
      "enabled": true
    }
  }
}
```

**Flutter 模型**：
```dart
class WorldInfoEntry {
  String id;
  List<String> key;
  List<String> secondaryKeys;
  String content;
  int insertionOrder;
  bool enabled;
}
```

### 4.2 HTTP 客户端封装

```dart
class SillyTavernClient {
  final Dio _dio;
  final String baseUrl;

  SillyTavernClient({required this.baseUrl}) {
    _dio = Dio(BaseOptions(
      baseUrl: baseUrl,
      connectTimeout: const Duration(seconds: 10),
      receiveTimeout: const Duration(minutes: 5),
    ));

    // Cookie 管理
    _dio.interceptors.add(CookieManager(CookieJar()));

    // SSE 流式响应
    _dio.interceptors.add(InterceptorsWrapper(
      onResponse: (response, handler) {
        if (response.responseType == ResponseType.stream) {
          // 处理流式响应
        }
        handler.next(response);
      },
    ));
  }

  // 登录
  Future<void> login(String handle, String password) async {
    await _dio.post('/api/users/public/login', data: {
      'handle': handle,
      'password': password,
    });
  }

  // 获取角色列表
  Future<List<Character>> getCharacters() async {
    final response = await _dio.post('/api/characters/all');
    return (response.data as List)
        .map((e) => Character.fromJson(e))
        .toList();
  }

  // 发送消息（流式）
  Stream<String> sendMessageStream(Map<String, dynamic> body) async* {
    final response = await _dio.post(
      '/api/backends/chat-completions/generate',
      data: body,
      options: Options(responseType: ResponseType.stream),
    );

    await for (final chunk in (response.data as Stream<List<int>>)) {
      final str = utf8.decode(chunk);
      // 解析 SSE 格式: data: {...}
      if (str.startsWith('data:')) {
        yield str.substring(5).trim();
      }
    }
  }
}
```

### 4.3 SSE 响应解析

```dart
Stream<String> parseSSEStream(Stream<List<int>> stream) async* {
  String buffer = '';

  await for (final chunk in stream) {
    buffer += utf8.decode(chunk);

    while (buffer.contains('\n')) {
      final lineEnd = buffer.indexOf('\n');
      final line = buffer.substring(0, lineEnd).trim();
      buffer = buffer.substring(lineEnd + 1);

      if (line.startsWith('data:')) {
        final data = line.substring(5).trim();
        if (data == '[DONE]') {
          return;
        }
        yield data;
      }
    }
  }
}
```

### 4.4 状态管理 (Riverpod)

```dart
// 连接状态
@riverpod
class ConnectionStatus extends _$ConnectionStatus {
  @override
  Future<ConnectionState> build() async {
    final prefs = await SharedPreferences.getInstance();
    final savedUrl = prefs.getString('server_url');
    if (savedUrl == null) return ConnectionState.disconnected;

    // 自动重连
    return _connect(savedUrl);
  }

  Future<ConnectionState> _connect(String url) async {
    try {
      final client = SillyTavernClient(baseUrl: url);
      await client.login('default', '');
      ref.read(clientProvider.notifier).state = client;
      return ConnectionState.connected;
    } catch (e) {
      return ConnectionState.error(e.toString());
    }
  }
}

// 角色列表
@riverpod
Future<List<Character>> characters(CharactersRef ref) async {
  final client = ref.watch(clientProvider);
  return client.getCharacters();
}

// 聊天消息
@riverpod
class ChatMessages extends _$ChatMessages {
  @override
  List<ChatMessage> build() => [];

  Future<void> sendMessage(String content) async {
    final client = ref.read(clientProvider);
    final body = _buildPrompt(content);

    await for (final chunk in client.sendMessageStream(body)) {
      final data = json.decode(chunk);
      final content = data['choices'][0]['delta']['content'];
      state = [...state, ChatMessage(content: content, isUser: false)];
    }
  }
}
```

## 5. 关键技术点

### 5.1 Cookie Session 管理

Dio 的 `cookie_manager` 插件可以自动处理 Cookie：
```dart
import 'package:dio_cookie_manager/dio_cookie_manager.dart';

final cookieJar = CookieJar();
dio.interceptors.add(CookieManager(cookieJar));
```

### 5.2 流式 UI 更新

使用 `StreamBuilder` 实现打字机效果：
```dart
StreamBuilder<String>(
  stream: messageStream,
  builder: (context, snapshot) {
    return Text(
      snapshot.data ?? '',
      style: Theme.of(context).textTheme.bodyLarge,
    );
  },
);
```

### 5.3 PNG 角色卡解析

Flutter 没有内置 PNG 元数据解析，需要使用 `image` 包：
```dart
import 'package:image/image.dart' as img;

img.PngInfo? parsePngMetadata(Uint8List bytes) {
  final image = img.decodePng(bytes);
  return image?.pngChunks;
}
```

或者使用 `png` 包直接解析 tEXt chunks。

### 5.4 断线重连

```dart
class ReconnectingClient {
  int maxRetries = 3;
  int retryDelay = 2; // 秒

  Future<String> sendWithRetry(Map<String, dynamic> body) async {
    for (int i = 0; i < maxRetries; i++) {
      try {
        return await _send(body);
      } catch (e) {
        if (i < maxRetries - 1) {
          await Future.delayed(Duration(seconds: retryDelay * (i + 1)));
        }
      }
    }
    throw Exception('Failed after $maxRetries retries');
  }
}
```
